1"""Constants for Home Keeper Library. 

2 

3Home Keeper Library is a companion of Home Keeper. It stores the books of a 

4household: the rooms, bookcases and shelves where the copies are, the reading 

5status of each person, the loans and the wishlist. The admin UI is a tab in the 

6Home Keeper panel. The usage surfaces are the card, the per-person entities and 

7the services. 

8 

9This module is pure. It imports no Home Assistant code, so the unit tier can load 

10it.
